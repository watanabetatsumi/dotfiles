# 全プロジェクト共通の指示（dotfiles の claude/CLAUDE.md。~/.claude/CLAUDE.md にリンクする）

## 作業は Codex に任せる（Claude のトークンを節約するため）

Claude（Opus）は、計画・判断・ユーザーとのやりとり・結果の確認を受け持つ。
コードを読んで調べる、実装する、テストを動かして直す、といった手を動かす作業は、
原則として `codex:codex-rescue` サブエージェント（openai/codex-plugin-cc）に任せる。

- Codex のモデルは `~/.codex/config.toml` の既定（gpt-6.1-sol）を使う。ユーザーが指示したときだけ `--model` / `--effort` を付ける。
- 任せるときは、目的・対象のファイルや範囲・完了の条件・確かめ方（実行するテストやコマンド）を具体的に書く。
  リポジトリの規約（そのリポジトリの CLAUDE.md・AGENTS.md）に従うよう添える。
- 戻ってきた結果は、そのまま信じずに確かめる。差分（`git diff`）とテストの結果を見て、問題があれば直しを Codex に頼む。
  確かめた内容をユーザーに報告する。
- 時間のかかりそうな作業は、裏で動かす（`--background`）。進み具合は `/codex:status`、結果は `/codex:result`。

Claude 自身でやってよいもの:
- 数行で済む変更、ファイルを1つ2つ読むだけの確認、ユーザーへの説明や文章の作成。
- ユーザーが「Claude がやって」と言ったとき。
- Codex を呼べないとき（エラーになったとき）。そのことをユーザーに伝えてから進める。

秘密情報（.env・トークン）を Codex への依頼文に書き写さない。
